# Strip Info

Enable `strip_info` in a pass list, for example:

```json
{"passes": ["strip_info", "string_obf", "rename_obf", "minify"]}
```

This preprocessing pass removes source comments, shortens lexical local names,
and renames fields of private tables before other transformations hide their
structure. It is also available in the GUI and VM/packer output pass lists.
`rename_obf` can still shorten helpers generated by later passes. Output
signatures are controlled separately by the signature settings.

A table qualifies only when directly constructed in a local declaration and
every reference is a direct static field access or a tracked local declaration
alias (`local alias = original`). Alias chains and closure captures are followed;
reassignment or escape through any alias disqualifies the entire table.
Dot keys, plain quoted strings, and long-string keys share one mapping per table;
numeric fields remain unchanged. Shadowed locals are analyzed separately.
Tracked closure captures are supported.

Static keys also include concatenations of string literals and quoted Lua
escapes: decimal bytes, hexadecimal bytes, standard character escapes, escaped
line breaks, and `\z` whitespace skipping. Keys are compared as bytes so escaped
UTF-8 sequences match literal UTF-8 text, while distinct raw bytes stay distinct.
Parentheses around constructors, aliases, receivers, and literal keys are
supported. Literal expressions are folded only when every operand is a known
string; variable-dependent expressions remain unchanged.

The entire table is skipped for reassignment, returning or exporting
the table, function arguments (including `pairs`, `next`, `rawget`, `rawset`,
and metatable operations), method syntax, or dynamic keys. Unsupported escape
forms (including `\u{...}`) and other key expressions are conservatively skipped.
Generated field names cannot collide with existing or missing-field keys.

Label declarations and `goto` targets are also renamed consistently, preserving
their original scope and control flow, including shadowed labels.

This is conservative source information stripping, not a guarantee that every
symbol or string disappears. Public fields and ordinary string values retain
their meaning. As with lexical renaming, programs that inspect local names or
upvalues through the debug API are outside the supported equivalence contract.
Readable rename mode is ignored by this pass so original names are not retained;
the configured rename seed still controls name allocation.
